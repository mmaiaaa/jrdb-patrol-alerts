# Cubberly development: native 2D / 3D reference consistency (draft)

The JRDB 2022 `labels.zip` archive contains five `labels/labels_2d_activity_social/<sequence>_image{0,2,4,6,8}.json` members for Cubberly, each with `labels` covering 1,296 frames. It has no `labels/labels_2d/<sequence>_image*.json` members. The former folder provides the candidate native-camera pedestrian records; the [JRDB-Act paper](https://openaccess.thecvf.com/content/CVPR2022/papers/Ehsanpour_JRDB-Act_A_Large-Scale_Dataset_for_Spatio-Temporal_Action_Social_Group_and_CVPR_2022_paper.pdf) discusses reusing JRDB's pedestrian boxes and track IDs. Schema inspection found **all 13 evaluable near 3D IDs** in at least one of the five 2D files on the same selected frame, yielding **19 frame-camera-track pairs** on four selected development frames. In these records `box` was not a dictionary; the exact source representation must be validated before scoring.

`scripts/audit_jrdb_dev_native_2d_3d_reprojection.py` performs a bounded offline check of that representation and the coordinate-frame hypotheses. It accepts a 2D box only if it is a four-number `[x,y,w,h]` sequence or an `x/y/w/h` dictionary with positive, finite size, as in the [JRDB 2D-box parameterization](https://arxiv.org/html/1910.11792v4). If reported 2D `attributes.area` is available, it checks whether the median `w*h / area` for at least five pairs is within a broad plausibility interval (0.5 to 2). It reports example boxes and **refuses** to write a comparison CSV for unsupported formats or implausible area conventions. The actual file must still be inspected before interpreting its numbers.

For matching 3D and 2D track IDs on the **same frame and native camera**, the script projects the center of the annotated 3D box under the provisional *label-upper* and *label-ego* hypotheses. It counts each center as inside its annotated 2D box, outside that box but inside the image, or outside the image, and writes per-pair rows including the 2D no-evaluation, occlusion and truncation attributes. These counts are an *annotation-consistency diagnostic*, **not** detector accuracy, depth-estimation accuracy, sensor synchronization or proof of the annotation frame. The original JRDB paper states that 2D boxes were initialized by projecting annotated 3D boxes and refined manually, so this check is not an independent benchmark. No reference labels may feed the online sensing path; reserve untouched sequences for final testing.
