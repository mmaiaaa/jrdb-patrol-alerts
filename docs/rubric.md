Review criteria and required evidence

The supplied previous review scored novelty 4, methodology 5, code/reproducibility 4, statistics 3, integrity 6, claims/evidence 5, and literature comparison 3 out of 10. These were scores for the previous MOT study. No numerical grade has been assigned to the unexecuted JRDB study.

| Criterion | Evidence required | Current status |
|---|---|---|
| Novelty | Closest prior work, a specific difference, strong baselines, ablations showing that the difference matters | Open |
| Methodological rigor | Audited metric task, causal decisions, independent references, fair comparisons, frozen test | Protocol draft only |
| Code correctness/reproducibility | Verified adapter/transforms, sound matcher, scientific edge-case tests, locked runnable artifact | Foundation only |
| Statistical validity | Independent recording groups and adequate exposure, paired effect intervals, transparent denominator choices | Planned |
| Data integrity | Exact release, manifests, exclusions, pretrained-data disclosure, separation of labels and predictions | Manifest headers only |
| Claims/evidence | Supported proximity/intrusion distinction, actual hardware/runtime measurements, evidence-linked claims | Draft limits explicit |
| Literature comparison | Full reading of closest patrol/alert research and compatible comparisons | Starting references only |

Work that raises rigor without creating novelty is still useful, but does not remove the novelty requirement. If a tuned simple baseline matches the proposed method, revise the contribution based on the finding rather than selecting a weaker comparator. More computing power or a more robotics-relevant dataset does not itself prove a journal-level contribution.
